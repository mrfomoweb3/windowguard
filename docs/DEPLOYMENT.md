## Public verification

The production URL returned HTTP 200 from Cloudflare with a cache hit. A browser loaded the deployed JavaScript, dynamically discovered a real BTC five-minute market, displayed on-chain Trading status, detected a market-ID roll, and rendered a fresh book snapshot. The observed post-roll book had no executable asks inside the configured maximum, so the Guard returned `INSUFFICIENT_DEPTH` and kept submission disabled.

Deployments use the static `out/` artifact generated by `next build` and configured in `wrangler.jsonc`.
